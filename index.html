Wieso ein Zertifikat nötig ist

Apple Wallet akzeptiert ausschliesslich .pkpass-Dateien, deren Inhaltsverzeichnis mit einem Pass Type ID Zertifikat signiert ist. Dieses gibt es nur über das Apple Developer Program.

So kommst du dran: Developer-Konto lösen, unter Identifiers eine Pass Type ID anlegen, das Zertifikat erzeugen, in der Schlüsselbundverwaltung als .p12 exportieren. Das WWDR-Zwischenzertifikat lädst du bei Apple im Bereich Certificates herunter.

Hinweis zu Fahrscheinen: Codes von Anbietern wie SBB sind oft signierte Aztec-Codes und dürfen nicht in ein anderes Format umkodiert werden – behalte in Schritt 1 das erkannte Format bei. Ob ein selbst gebauter Pass am Kontrollgerät akzeptiert wird, entscheidet der Anbieter, nicht das Format.
